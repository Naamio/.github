# Naamio

Naamio builds open source tools and services that keep personal data under the
control of the people it belongs to. The projects cover identity, messaging,
storage, and the open standards that let data move between platforms.

The work improves the privacy and portability of data and services across
platforms, reduces the technical knowledge needed to run them, and makes open
source software, services, and tooling more accessible.

## Projects

| Project | Description |
|---|---|
| [Wallet](https://naamio.dev/wallet) | Self-sovereign identity wallet supporting passkeys, verifiable credentials, and open standards |
| [Email](https://naamio.dev/email) | Self-sovereign, portable email built on JMAP, IMAP, and SMTP |
| [Chat](https://naamio.dev/chat) | Private, self-hostable real-time communications based on Matrix |
| [Social](https://naamio.dev/social) | Open social standards including ActivityPub, AT Protocol, and federated social networking |
| [Space](https://naamio.dev/space) | Secure, portable personal data storage with end-to-end encryption and open synchronisation protocols |
| [Contacts](https://naamio.dev/contacts) | Contact management using vCard, JMAP, and CardDAV |
| [Calendar](https://naamio.dev/calendar) | Calendar and scheduling using iCalendar, JMAP, and CalDAV |
| [AT Protocol](https://naamio.dev/at-protocol) | AT Protocol implementations and tooling |

## Origin of works

## Governance

Naamio is governed by the [Omnifi Foundation](https://omnifi.foundation), a
community-driven organisation that stewards open source projects.
