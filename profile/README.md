# Naamio

Community-focused projects for the creation of safety-by-design, human-centric, self-sovereign data, intelligence, and service-based solutions.

As a core tenet of these projects, we are focused on improving privacy and portability of data and services across platforms, whilst reducing the technical requirements and improving accessibility of open source software, services, and tooling.

## Projects

| Project | Description |
|---|---|
| [Wallet](https://naamio.dev/wallet) | Self-sovereign identity wallet with anticipatory credential intelligence, supporting passkeys, verifiable credentials, and open standards |
| [Email](https://naamio.dev/email) | Privacy-respecting email services built on open standards including JMAP and IMAP |
| [Chat](https://naamio.dev/chat) | Private, self-hostable real-time communications based on Matrix |
| [Social](https://naamio.dev/social) | Open social standards including ActivityPub, AT Protocol, and federated social networking |
| [Space](https://naamio.dev/space) | Secure, portable data storage with end-to-end encryption and open synchronisation protocols |
| [Contacts](https://naamio.dev/contacts) | Contact management using open standards including vCard, JMAP, and CardDAV |
| [Calendar](https://naamio.dev/calendar) | Calendar and scheduling using open standards including iCalendar, JMAP, and CalDAV |
| [Pebble](https://naamio.dev/pebble) | Content syndication across open protocols and feeds |
| [AT Protocol](https://naamio.dev/at-protocol) | AT Protocol libraries and tooling in Rust |
| [Deus](https://naamio.dev/deus) | Web applications and interactive components for the Naamio ecosystem |
| [Dev](https://naamio.dev/dev) | Development tools, templates, and shared infrastructure |

## Origin of works

The canonical source for Naamio projects is hosted on [GitLab](https://gitlab.com/naamio). Selected repositories and releases may be mirrored to GitHub for public discovery and collaboration.

Naamio is governed by the [Omnifi Foundation](https://omnifi.foundation).
